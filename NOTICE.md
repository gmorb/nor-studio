**NOR Studio**: PS5 NOR editor, CH341A programmer and UART diagnostics.

  (https://github.com/TheCod3rYouTube/PS5NorModifier), licensed under the GNU GPL v2.0.

- The project was rebuilt and extended **with the help of AI assistance**.
- Improvements, extra features and ideas by **The Goat Tech**.
- NOR area layout was cross‑checked against **ps5‑wee‑tools** by andy‑man (GPL‑3.0). No code was copied from it.

  **Console Service Tool** by amoamare (https://github.com/amoamare/Console-Service-Tool).

  project were reimplemented independently. No code or images were copied; reference
